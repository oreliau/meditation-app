# Adopt react-native-unistyles v3 for cross-platform theming

The app needs a single theming system that renders correctly on both Expo Router web (`web.output: "static"`) and native, driven by the two Aura palettes in `DESIGN.md`, with adaptive OS-following and a persisted manual override. We chose `react-native-unistyles` v3 over v2 (legacy API, no first-class web/New Architecture support) and over CSS-in-JS alternatives like NativeWind/Tamagui, because v3's Nitro/C++ core targets RN 0.86's New Architecture directly and has first-class `react-native-web` support, matching this app's SDK 57 / React 19 / New Architecture baseline. This is a pervasive, hard-to-reverse choice — every styled component in the app will depend on its theme/breakpoint API — so a future reader shouldn't need to re-derive why NativeWind (the more common Expo default) wasn't picked instead.
